# Enclosure

3D-printable and CAD case files for the Stardance Hackpad.

## Files

- **CAD_Stardance_hackpad_case_top.step / .stl** — top case shell
- **CAD_Stardance_hackpad_case_bottom.step / .stl** — bottom case shell
- **CAD_Stardance_hackpad_top_plate.step / .stl** — top plate (switch/OLED cutouts)
- **CAD_Stardance_hackpad_final_assembly.step** — full assembly (case + plate + PCB), STEP format
- **CAD_Stardance_hackpad_final_assembly.f3z** — full assembly, Fusion 360 archive format
- **Stardance_hackpad_final_assembly.stl** — full assembly, STL

Print the case top, case bottom, and top plate. See the main [README](../README.md) for build steps.
